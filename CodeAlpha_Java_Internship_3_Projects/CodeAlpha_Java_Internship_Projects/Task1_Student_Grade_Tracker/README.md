# Task 1 — Student Grade Tracker

## Features
- Add student names and scores (0–100).
- Store records in an `ArrayList`.
- Display all students.
- Calculate average, highest and lowest scores.
- Save and reload records using `students.csv`.

## Requirements
Java JDK 8 or later.

## Run
Open a terminal in this folder:
```bash
javac Main.java
java Main
```
The `students.csv` file is created automatically after the first record is added.

## Concepts demonstrated
Classes and objects, `ArrayList`, loops, methods, input validation, file handling and exception handling.
