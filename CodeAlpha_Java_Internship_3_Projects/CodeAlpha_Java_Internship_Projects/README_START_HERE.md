# CodeAlpha Java Programming Internship — Selected Tasks

This package contains three independent Java console projects:
1. Task 1 — Student Grade Tracker
2. Task 3 — Artificial Intelligence Chatbot (rule-based)
3. Task 4 — Hotel Reservation System

These were selected as a practical combination of Java fundamentals, OOP, collections, text processing and file handling.

## How to run each project
1. Install JDK 8 or later.
2. Open the required task folder in VS Code or a terminal.
3. Run `javac Main.java`.
4. Run `java Main`.

Each project has its own README with features and details. Run each project from its own folder so its data file is stored there.
