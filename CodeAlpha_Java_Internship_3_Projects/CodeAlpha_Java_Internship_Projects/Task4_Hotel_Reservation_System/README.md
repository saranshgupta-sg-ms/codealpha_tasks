# Task 4 — Hotel Reservation System

## Features
- Room categories: Standard, Deluxe and Suite.
- View all rooms and search currently available rooms.
- Book a room for one or more nights.
- Simulated payment confirmation.
- View booking details and cancel a booking.
- Save and reload bookings using `bookings.csv`.

## Requirements
Java JDK 8 or later.

## Run
```bash
javac Main.java
java Main
```
The `bookings.csv` file is created automatically when a booking is saved.

## Important scope note
This is an educational console simulation. It does not connect to a real hotel, payment gateway, calendar, or database. Room availability is tracked by active bookings in the local file.

## Concepts demonstrated
OOP classes and objects, `ArrayList`, methods, loops, input validation, file handling and exception handling.
