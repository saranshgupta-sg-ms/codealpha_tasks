# CodeAlpha Java Programming Internship Projects

This repository contains three Java console-based projects developed for the CodeAlpha Java Programming Internship.

## Projects

### 1. Student Grade Tracker
Add student names and marks, view records, and calculate the class average, highest score, and lowest score. Records are saved in `students.csv`.

**Concepts:** Core Java, classes and objects, ArrayList, loops, methods, input validation, file handling, and exception handling.

**Run:**
```bash
cd Task1_Student_Grade_Tracker
javac Main.java
java Main
```

### 2. AI Chatbot (Rule-Based)
An interactive chatbot that matches keywords with answers stored in a predefined knowledge base.

**Important:** This is a rule-based chatbot demonstration, not a trained machine-learning model or advanced NLP system.

**Concepts:** Core Java, Map, strings, loops, methods, conditional logic, and basic text processing.

**Run:**
```bash
cd Task3_AI_Chatbot
javac Main.java
java Main
```

### 3. Hotel Reservation System
View rooms, search availability, book a room, simulate payment, view booking details, and cancel a booking. Booking information is saved in `bookings.csv`.

**Important:** Payment is simulated only. The project is not connected to a real hotel, payment gateway, or database.

**Concepts:** OOP, classes and objects, ArrayList, methods, input validation, file handling, and exception handling.

**Run:**
```bash
cd Task4_Hotel_Reservation_System
javac Main.java
java Main
```

- Java Development Kit (JDK) 8 or later
- Terminal / Command Prompt or an IDE such as VS Code
